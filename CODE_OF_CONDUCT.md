# Codice di condotta

Questo progetto adotta il [Contributor Covenant, versione 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
([traduzione italiana](https://www.contributor-covenant.org/it/version/2/1/code_of_conduct/)).

In breve: chi partecipa (issue, pull request, discussioni) si impegna a un confronto rispettoso e
privo di molestie, qualunque siano età, corporatura, disabilità, etnia, identità ed espressione di
genere, livello di esperienza, istruzione, condizione socio-economica, nazionalità, aspetto,
religione, identità e orientamento sessuale.

**Segnalazioni.** I comportamenti inaccettabili si segnalano in privato al maintainer, tramite la
segnalazione privata di GitHub (scheda **Security** → **Report a vulnerability**, indicando nel
titolo «codice di condotta»). Ogni segnalazione viene esaminata con riservatezza. Le conseguenze
seguono le linee guida del Contributor Covenant 2.1: correzione, avvertimento, sospensione
temporanea, esclusione permanente.
